Task

A cubature rule is a sum Σ wᵢ f(xᵢ) that reproduces the integral of f over the domain exactly for all polynomials of total degree ≤ n. The goal is the smallest number of nodes N. Additionally all weights are positive and all nodes lie in the closed domain. Surveys: [6][7].

Reference domains

  • Interval [−1,1], length 2
  • Square [−1,1]², area 2² = 4
  • Triangle (0,0), (1,0), (0,1), area ½
  • Tetrahedron (0,0,0), (1,0,0), (0,1,0), (0,0,1), volume ⅙
  • Cube [−1,1]³, volume 8

Notation

n: degree, d: dimension, N: number of nodes. PI (positive, inner): positive weights, all nodes in the closed domain (boundary points count). This is the condition of the atlas. PO (positive, outer): positive weights, nodes may also lie outside.

Columns: NPI smallest known PI rule, Z counting value (for square and cube the smaller of the general and the symmetric counting value), Δ = NPI − Z, L lower bound, NG Gauss product, NLit smallest literature value (Xiao–Gimbutas or symmetric rules), NPO smallest known PO rule.

Column NPI (smallest known PI rule)

Number of nodes of the smallest rule this page knows for the degree. It comes from a numerical search of its own (section Search method) and is checked against all monomials, checked numerically (Newton–Kantorovich) and proven with interval arithmetic. Every rule is also a valid rule for all smaller degrees.

Column Δ

Difference “found” minus counting value. Negative values mean the rule is smaller than the rule of thumb.

Counting value

The moment equations form a nonlinear system. Counting equations and unknowns suggests that a rule needs about this many nodes:

Z(n, d) = ⌈ M(n, d) / (d + 1) ⌉
M(n, d) = C(n+d, d) = (n+d)! / (n!·d!)

Here n is the degree, d the dimension (interval 1, triangle and square 2, tetrahedron and cube 3), M(n,d) the number of monomials of degree ≤ n (the dimension of the polynomial space) and Z(n,d) the counting value. Each node brings d coordinates and one weight, i.e. d+1 unknowns. Example, triangle, n = 20: M = C(22,2) = 231, Z = ⌈231/3⌉ = 77. One more degree adds exactly the monomials of exact degree n+1, M(n+1,d) − M(n,d) = C(n+d, d−1), so Z grows per degree by about

Z(n+1, d) − Z(n, d) ≈ C(n+d, d−1) / (d + 1)

Written out:

d = 2: Z(n) = ⌈ (n+1)(n+2) / 6 ⌉
Z(n+1) − Z(n) ∈ { ⌊(n+2)/3⌋, ⌈(n+2)/3⌉ }

d = 3: Z(n) = ⌈ (n+1)(n+2)(n+3) / 24 ⌉
Z(n+1) − Z(n) ∈ { ⌊(n+2)(n+3)/8⌋, ⌈(n+2)(n+3)/8⌉ }

So up to rounding the increase per degree is (n+2)/3 for the triangle and (n+2)(n+3)/8 for the tetrahedron. For large n, Z ≈ nᵈ / (d!·(d+1)) while the Gauss product grows like (n/2)ᵈ, so the ratio is ≈ 2ᵈ/(d!·(d+1)): 2/3 for triangle and square (4/(2·3)), 1/3 for tetrahedron and cube (8/(6·4)). The value is a rule of thumb and not a bound: rules can lie below or above.

Square and cube: symmetric counting value

Square and cube are centrally symmetric. If a rule is symmetric under x ↦ −x (equal weights at x and −x), every monomial of odd degree is integrated exactly by symmetry, because integral and sum both vanish. Only the monomials of even degree remain as equations, and a node pair ±x brings d+1 unknowns for 2 nodes:

E(n, d) = Σj even, j ≤ n C(j+d−1, d−1)
Zsym(n, d) = ⌈ 2·E(n, d) / (d + 1) ⌉

For square and cube the column Z shows the smaller of both values:

Z = min( ⌈ M(n, d) / (d + 1) ⌉, Zsym(n, d) )

Which one is smaller depends only on the parity of n. Split the monomials of degree ≤ n into E of even and O of odd degree, M = E + O. Then Zsym < Z exactly when O > E. The layer of exact degree j has C(j+d−1, d−1) monomials, which grows with j, so the top layer decides: for odd n there are more odd monomials and the symmetric value is smaller; for even n there are more even monomials, a symmetric rule is automatically exact for degree n+1 as well and pays for that with extra nodes, so the general value is smaller. Hence Zsym(2k) = Zsym(2k+1) and

Z(2k) ≤ Zsym(2k+1) ≤ Z(2k+1) (general Z)

Written out for odd n:

d = 2: Z(n) = ⌈ (n+1)² / 6 ⌉
d = 3: Z(n) = ⌈ (n+1)(n+3)(2n+1) / 48 ⌉

This lowers the counting value at odd degrees by about (n+1)/6 for the square and (n+1)(n+3)/16 for the cube. Example cube, n = 9: E = 1+6+15+28+45 = 95, Z = 48 instead of 55; the found rule has 48 nodes and is centrally symmetric.

Triangle and tetrahedron have no centre of symmetry: the map x ↦ −x (about the centroid) takes them to a different set, so no rule can have this symmetry, odd moments do not vanish, and the general counting value applies. In the interval both values agree for odd n, Gauss rules are symmetric and optimal at the same time.

Lower bound

  • Degree 2k: at least dim Pk = C(k+d,d) nodes, for any domain [2]. For even degrees no sharper general bound is known [7][15], and at small degrees none is possible: the bound is attained on the triangle at degrees 2, 4, 6 (3, 6, 10 nodes; at degree 6 only by the PO rule), on the square at degrees 2 to 8 (3, 6, 10, 15 nodes; at degree 8 by the PO rule), on the tetrahedron and the cube at degrees 2 and 4 (4 and 10 nodes; tetrahedron degree 4 by the PO rule).
  • Odd degrees 2k−1 on the square: the sharper Möller bound dim Pk−1 + ⌊k/2⌋ [2].
  • Odd degrees 2k−1 on the triangle: the same value dim Pk−1 + ⌊k/2⌋. It follows from Möller's general bound [3], which needs no symmetry, in the form given by Xu [21]: N ≥ dim Pk−1 + ½·rank(Ak−1,1Ak−1,2T − Ak−1,2Ak−1,1T). The Ak−1,i are the matrices of the three-term relation xiPk−1 = Ak−1,iPk + … of the orthonormal polynomials (Dubiner basis). The matrix in the bracket is skew-symmetric of size k, so its rank is even and at most 2⌊k/2⌋. The program triangle_moeller.py computes the rank exactly with fractions: for every odd degree from 3 to 29 it is maximal. Consequences: the rules with 4, 7 and 12 nodes at degrees 3, 5 and 7 are minimal, and since the rank is never 0 there is no Gauss rule with only dim Pk−1 nodes on the triangle (Mysovskikh's condition fails). The bound holds for any real weights and nodes anywhere; a short proof is in the header of moeller_bound.py.
  • Odd degrees 2k+1 on the tetrahedron: the same argument in three variables. With the three matrices Mij = Ak,iAk,jT − Ak,jAk,iT it gives N ≥ dim Pk + ρ with ρ ≥ ⌈rank Mij/2⌉ for every pair and ρ ≥ ⌈rank(M12|M13|M23)/3⌉. The program moeller_bound.py computes the ranks exactly modulo a prime; a rank modulo a prime is never larger than the rational rank, so the values are proven. For all odd degrees from 3 to 29 the pair ranks are dim Vk − ⌈(k+1)/2⌉ (dim Vk = (k+1)(k+2)/2), which gives L = dim Pk + (dim Vk − ⌈(k+1)/2⌉)/2, e.g. 5, 12, 24, 41 nodes at degrees 3, 5, 7, 9 (before: 4, 10, 20, 35).
  • Odd degrees 2k+1 on the cube: Möller's bound for centrally symmetric integrals [3], N ≥ 2·dim Pkodd for odd k and N ≥ 2·dim Pkeven − 1 for even k, where Pkeven, Pkodd are the polynomials of degree ≤ k made of monomials of even or odd degree. In the explicit form of Hinrichs and Novak [11] this is 2d, d2+d+1 and (d3+3d2+8d)/3 at degrees 3, 5, 7. For the cube it is larger than the bound from the structural matrices (which gives the tetrahedron values). Consequence: the cube rules with 6, 13 and 26 nodes at degrees 3, 5 and 7 are minimal.
  • Positive weights, tetrahedron degree 3: at least 6 nodes (the general bound 5 is attained only with a negative weight). With 5 nodes the discrete Gram matrix K of the orthogonal polynomials of degree 2 has rank 1, K = s·ggT. The equations s·(ai × aj) = mij with ai = A1,ig have a real solution only if s·c12c13c23 > 0, where mij = cij(ui × uj) for fixed vectors ui. The exact values give c12c13c23 < 0, so s = −1, which is impossible for positive weights (K is then positive semidefinite). The program tetra3_positive.py carries out the proof with fractions. So the 6-node rule is minimal among rules with positive weights, wherever the nodes lie.
  • Tetrahedron degree 5: at least 13 nodes for any real weights (the structural bound gives 12). With 12 nodes, K has rank 2, K = GSGT with S = diag(±1, ±1), and Bi = A2,iG gives Mij = BiSBjT − BjSBiT. Since rank Mij = 4, the column spaces Si of Bi are complementary planes in the column space of Mij and Lagrangian for the 2-form inverse to Mij. In exact arithmetic these conditions determine S1, S2, S3 uniquely; then the equations are linear in Pij = XiSXjT (Bi = SiXi), and (P12P23−T)−1P13 = X3SX3T would have to be symmetric. It is not, so no such rule exists. The program tetra5_bound.py carries out the proof with fractions; its option --selftest checks the procedure on artificial data with known G and S of every signature.

Gauss product

The rule built from one-dimensional Gauss formulas needs ⌈(n+1)/2⌉d nodes. On the triangle and tetrahedron it arises through collapsed coordinates (Duffy map) with Gauss–Jacobi formulas. It serves as a yardstick and grows like nd/2d.

Column NLit (literature)

Smallest value of the Xiao–Gimbutas rules [14] and the fully symmetric rules from the literature (Witherden–Vincent [17], Jaśkowiec–Sukumar [18][19], Diallo–Worku [24]). The source of each row follows the value. On a tie both are listed. The next two sections describe the sources one by one.

Xiao–Gimbutas

Node counts of the numerically constructed rules of Xiao and Gimbutas [14] (triangle and square up to degree 20, tetrahedron up to degree 12 recorded here; for the triangle they coincide with [9][17]). The rules have positive weights and nodes inside the domain. No values are recorded for the cube, so the column is omitted there.

Literature, fully symmetric

Smallest known rules with the full symmetry group of the domain, positive weights and interior nodes: square [17][24], tetrahedron [17], cube [17][24]. For every degree the smallest rule of degree ≥ n is listed. Full symmetry is convenient for the finite element method and costs nodes, so these values lie above the ones found here. The rules of [18][19] for the tetrahedron up to degree 20 are also fully symmetric; their node counts are not recorded here.

Column NPO (positive weights, nodes outside allowed)

This column (triangle, square and tetrahedron) holds PO rules and is not a PI rule in the atlas sense: weights are positive, but single nodes may lie outside the domain (Duffy parameters in [−0.7, 1.7]). Such rules often need fewer nodes, e.g. on the triangle at degree 12: 31 instead of 32 nodes, exactly the counting value. Below the counting value the search found nothing even with this relaxation. Nodes outside need a function that is defined there, so the rule is not usable for √ or log. It may also amplify rounding errors more than an interior rule. The numbers come from our own search; every rule smaller than the PI rule is proven with interval arithmetic like the PI rules. A value equal to NPI means the search with outside nodes found no smaller rule. A “–” means not searched yet.

Search method

  • Damped Gauss–Newton (Levenberg–Marquardt) on the moment equations in an orthonormal basis: Legendre products, or Dubiner polynomials for simplices.
  • Simplices are mapped to parameter boxes [0,1]d by the Duffy map so nodes never leave the domain.
  • Start with random nodes just above the counting value, then node removal: the node with a small weight is dropped and the rest is solved again. High degrees start from the rule of the previous degree plus extra nodes.
  • Square and cube use central symmetry (pairs ±p) at odd degrees, which halves the unknowns. The approach follows the methods in [14] and the survey [7].

Computing accuracy in the error plot

With 64-bit numbers (unit roundoff u = 2−53 ≈ 1.1·10−16) the error cannot become arbitrarily small. The orange line is a bound in two parts: (N+2)·u·Σ|wᵢ f(xᵢ)| for rounding in the summation and in the function evaluation, divided by |I|, plus the measured effect of rounding nodes and weights to 15 digits (eight random patterns of ±5·10−16). For oscillating functions such as the sine, Σ|wᵢ f(xᵢ)| is much larger than |Q|, so the bound sits near 10−14 instead of 10−16. Errors below the line are rounding noise and say nothing more about the rule.

Moment check

Every rule was checked independently against the exact integrals with all monomials up to degree n (weights positive, nodes inside the domain). The Proof section lists the largest residual in the orthonormal basis, computed from the 15 decimals stored on this page.

Numerical check for a nearby solution (not a proof)

For x₀ = (nodes, weights), F(x) maps to the moments. The system is underdetermined (unknowns ≥ equations) and the Jacobian J(x₀) has full row rank. With σ the smallest singular value of J, η = ‖J⁺F(x₀)‖ and a Lipschitz constant L of J, the Newton–Kantorovich theorem for underdetermined systems (Ben-Israel) applies: if h = L·η/σ² ≤ ½, an exact solution x* exists with ‖x*−x₀‖ ≤ 2η.

For centrally symmetric rules the reduced system for the pairs ±p is used. L is estimated in 40 random directions and multiplied by 2. This is a numerical check in floating point and not a proof; the proof is the interval proof (tools/verify_rigorous.py). Whether the ball around x₀ contains weights ≤ 0 or points outside is shown in the last column.

Why does the Gauss product sometimes beat a rule with fewer nodes?

The degree only says up to which polynomials a rule is exact. How well it integrates a particular smooth function depends on its error for the terms above. Measured on the square (orthonormal Legendre products of degree n+1 to n+7, root mean square error) there are three reasons.

  • Symmetry. The Gauss product is point symmetric and so integrates every term of odd total degree exactly, half of all terms. The minimal-node rules lack this symmetry; their error at degrees n+1, n+3, … lies between 0.2 and 0.9.
  • Tensor space. An m×m product is exact on all xiyj with i, j ≤ 2m−1, i.e. 4 functions per node. The minimal rules are exact on all polynomials up to degree n, only about 3 functions per node. At even degrees above, the product misses only terms with one exponent too high; the error there is 3 to 10 times smaller (n = 18, 64 nodes, degree 20: 0.39 against 0.11).
  • No slack. A rule at the lower node bound satisfies exactly the moment equations up to degree n. No degree of freedom is left for the error above.

Consequence: functions that are almost a polynomial of degree ≤ n win with the minimal rule (on the square for |sin 2z|² and sinc from degree 10). Functions with strong terms above, such as the sine with frequency 4, the banana or the cosine test function, often win with the Gauss product. The error curves below show both; this does not contradict the node counts in the table.

More test functions: Ackley and Genz

The Ackley function [28] is a standard optimisation benchmark. It is smoothed here (√(m + δ²) with δ = 0.3 instead of √m), because the cusp at the origin would otherwise limit every reference computation to a few digits. The four Genz families oscillatory, product peak, corner peak and Gaussian are smooth and have closed-form integral values [23]. They are defined in u = (x + 1) / 2 on the unit cube, or in the coordinates x of the simplex. On square and cube the closed formula is the exact value, on triangle and tetrahedron a high-order Gauss product. The Genz families “continuous” and “discontinuous” are left out because non-smooth functions limit every rule to the same low accuracy.

Cosine test function

Diallo and Worku [24] test with cos(10x + 25y) on the square. That oscillates so strongly that hardly any error drops below 1 up to degree 30. Here we use f = 1 + cos(t₁ + π·t₂) instead (on the cube 1 + cos(t₁ + π·t₂ + 2·t₃)). The 1 is needed: on a symmetric domain the integral of cos(x + πy) is 0, so a relative error would be undefined. The constant does not change the absolute error of the rules, it only gives a denominator ≠ 0. On square and cube the exact value is 2d + Π 2·sin(aᵢ)/aᵢ, on triangle and tetrahedron (t = 2x − 1) a high-order Gauss product.

Origin of the rules and reproduction

Every rule in the tables passed these checks before it was accepted: the monomial check (all monomials up to degree n, error below 10−12), the numerical Newton–Kantorovich check (h ≤ ½) and the interval proof (tools/verify_rigorous.py). For PI rules the whole ball around the solution must also stay inside the domain with all weights positive. Rules that fail are discarded and not shown. Nodes and weights are stored with 15 digits; the numerical check and the interval proof are computed for the rounded data.

  • Interval: closed formulas. Gauss–Legendre: N = ⌈(n+1)/2⌉ nodes, the zeros of PN. Gauss–Lobatto: N = ⌈(n+3)/2⌉, the end points and the zeros of P′N−1. Clenshaw–Curtis: Chebyshev extrema cos(jπ/(N−1)). Equidistant (Newton–Cotes): equally spaced nodes with end points. For the three interpolatory rules the weights come from the linear system of Legendre moments up to degree N−1; N is the smallest node count whose rule reaches degree n.
  • Triangle and tetrahedron: kubatur.py (start nodes, Levenberg–Marquardt, node removal) up to about degree 20; above, start from the rule of the previous degree plus new nodes in the largest gaps (seed_tri2.py, random starts with seed 100+s). Triangle degree 25 (117 nodes) comes from this start-from-previous-degree search.
  • Square: degrees 1 to 20 with dom.py/cs.py (solver, central symmetry), degrees 21 to 30 with seed_sq.py (even degrees, no symmetry, start from a lower degree) and seed_cs.py (odd degrees, centrally symmetric: pairs ±p, below the counting value from degree 9). Central symmetry gave no gain at even degrees.
  • PO: the same solvers with widened bounds (triangle: Duffy parameters in [−0.7, 1.7], square: coordinates in [−3, 3]), weights ≥ 0 (free_search.py, sqelim.py in mode b). PO = PI where the search found nothing smaller.
  • Cube: fully symmetric rules (group Oh or Td) from cubature_search.py (orbit types, symmetry reduction, post-processing), re-checked with verify_rules.py. These rules are marked ‡; their numerical check and their interval proof use the symmetry-reduced system (cube_cert.py, run with python run_cube_cert.py 2,10,14 a).
  • Orbit search for triangle and tetrahedron (symsearch.py, orbit types under S₃ and S₄): no gain so far over the rules above. Tetrahedron from degree 24: no rule below the Gauss product yet.

Reproduction. All scripts are in the source code section. Put them in one directory with a subfolder lib/ (holding cubature_atlas.py). Packages: numpy, scipy. The start-from-previous-degree scripts read start rules from allrules30.json (format {"rules": {domain: {degree: {"n": nodes, "pts": [[coordinates…, weight], …]}}}}); the point list of each rule can be copied from Figure A. Examples:

python kubatur.py auto triangle 12 --time 600
python seed_tri2.py 25 2 117 20 120
python seed_sq.py 22 2 92 d 12 150
python seed_cs.py 21 81 d 8 100
python sqelim.py 30 b 80 1
python free_search.py triangle 14,18 20

The scripts write rules as .npy (columns: coordinates, weight) and save only after the monomial check and the numerical check pass; the interval proof follows before a rule is added to the atlas. python kubatur.py check rule_triangle_d12_n34.npy checks a file. Run times: seconds to a few minutes per attempt on two cores; random starts are fixed by seeds, but results depend on library versions and rounding. The numbers on this page are upper bounds for the true minimum.

How the figures are made

Figure A: the dancing polynomial is a linear combination of the Legendre basis (products on the square and cube) up to degree n with time-shifted phases, normalised to maximum 1. On the interval the grey area shows the integral, the bars show width = weight and height = polynomial value at the node. In 2D and 3D the nodes carry columns or cells: the tiling of the domain is a power diagram (weighted Voronoi diagram) whose cell areas are iterated (up to 300 steps, step size 0.4, 22 nearest neighbours) until they equal the weights; in 3D these are plain Voronoi cells. Green: value positive, red: negative, orange: negative weight.

Figures C to E: the error is relative to the exact value (analytic or high-order Gauss reference); the orange line is the computing accuracy (see above).

Limits

Node counts are upper bounds for the true minimum. That no smaller rule exists is proven only where “found” equals the lower bound.
