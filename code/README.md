# Code

The programs that produced the rules and checked them numerically, as published on the original atlas page. Their floating-point Newton–Kantorovich test is a numerical check, not a proof; the proofs come from `tools/verify_rigorous.py`. They need numpy and scipy.

| File | Purpose |
|---|---|
| `import_xiao_wandzura.py` | The rules printed in Wandzura–Xiao (2003, Tables 3–8) and Xiao–Gimbutas (2010, Tables 5–8): expands the printed generator nodes with the symmetry group, maps the triangle to (0,0), (1,0), (0,1), checks the moment equations and writes the rule files and the two `family.json` files |
| `counts.py` | Counting value, lower bounds, Gauss product |
| `triangle_moeller.py` | Triangle, odd degrees: exact Möller lower bound dim P_k + rank(M_k)/2 from the three-term relation (fractions, no numpy); shows that no Gauss rule exists and that the degree 3, 5 and 7 rules (4, 7, 12 nodes) are minimal |
| `moeller_bound.py` | Lower bounds for odd degrees (triangle, square, tetrahedron, cube) from the structural matrices of the three-term relation, exact modulo a prime (numpy); contains a short proof valid for any real weights; gives the tetrahedron column L |
| `tetra3_positive.py` | Tetrahedron degree 3: exact proof that no 5-node rule with positive weights exists (nodes anywhere), fractions only |
| `tetra5_bound.py` | Tetrahedron degree 5: exact proof that no 12-node rule exists for any real weights (Lagrangian-subspace elimination of the structural equations); `--selftest` validates the procedure on artificial data |
| `moment_relaxation.py` | Numerical moment relaxation for odd degrees (triangle, tetrahedron): can the discrete Gram matrix of P_{k+1} be PSD of rank r? Used for the open question triangle degree 9 |
| `cubature_atlas.py` | Basis, search, numerical Newton–Kantorovich check |
| `demo.py` | Find a rule, check it numerically, integrate |
| `kubatur.py` | Triangle/tetrahedron search with numerical check |
| `dom.py`, `cs.py`, `fj.py` | Basis and solver (square, triangle, tetrahedron) |
| `seed_sq.py`, `seed_cs.py` | Square, start from a lower degree |
| `sqelim.py` | Square, node reduction (PI and PO) |
| `seed_tri2.py`, `free_search.py` | Triangle/tetrahedron, start from the previous degree, PO search |
| `symsearch.py` | Orbit search (triangle, tetrahedron) |
| `simplex_cubature.py` | d-simplex search with symmetry groups S_{d+1}, A_{d+1} or none: invariant basis from the orthonormal Dubiner basis, NNLS start, orbit elimination with Levenberg–Marquardt and manifold walks; produced the tetrahedron rules CA-T3-24-766 … CA-T3-30-1704 |
| `cannonball_start.py` | Tetrahedron search started from a cannonball packing of about Z(n) = (n+1)(n+2)(n+3)/24 equal balls (the counting value), degree continuation with bounded least squares (scipy trf), optional node elimination; produced CA-T3-10-74 |
| `cannon_cube.py` | Cube: start from a T_d- or O_h-invariant cannonball packing (FCC lattice) with equal weights, solve the symmetry-reduced system, then orbit elimination and LNS of `cubature_search.py` (`sym`, `cont` modes); free mode with exactly Z(n) nodes without symmetry; produced CA-C3-24-730 and CA-C3-22-551 |
| `cannon_tetra.py` | Tetrahedron: start from a cannonball pile (K layers, S4-invariant), degree continuation from a low degree up to n, then orbit elimination of `simplex_cubature.py` with groups S and A; `--start` continues from a saved rule; produced CA-T3-28-1181 and CA-T3-29-1480 |
| `cert_large.py` | Numerical check for large simplex rules (tetrahedron degree 28 and up): same test as `certificate()`, with cached basis recursions and power iteration for the norms |
| `combo_search.py` | Triangle/tetrahedron: combines the orbit search of `simplex_cubature.py` (fresh NNLS starts, orbit elimination in S or A, small systems) with the asymmetric node elimination of `po_elim.py` (perturbations, merges, Levenberg-Marquardt) started from the expanded symmetric rule; INSIDE=1 keeps nodes in the closed domain (PI); produced CA-T3-10-73 and CA-T3-12-116 |
| `square_elim.py` | Square PI search: random start, bounded Levenberg-Marquardt, node elimination one node (or one centrally symmetric pair, `--cs`) at a time; `--po BOUND` lets the nodes leave the square (PO rules, coordinate bounds [-BOUND, BOUND]); `refine` removes one more node or pair from a saved rule with perturbed restarts (`--free` without symmetry, `--to-centre` turns a pair into a centre node); produced CA-C2-31-171 … CA-C2-39-268 |
| `triangle_elim.py` | Triangle PI search in collapsed (Duffy) coordinates with the orthonormal Dubiner basis: random start, bounded Levenberg-Marquardt, node elimination; `refine` removes one more node from a saved rule with perturbed restarts; produced CA-T2-31-177 … CA-T2-35-247 |
| `po_elim.py` | Cube/tetrahedron/triangle/square PO search: node elimination from the PI rule with nodes allowed outside the domain (CS=1: centrally symmetric pairs on the cube); produced CA-C3-06-21-PO … CA-C3-29-1181-PO and CA-T3-12-114-PO … CA-T3-24-757-PO |
| `shell_c3_search.py` | Triangle, exactly Z nodes: Gauss shell patterns (steps of -2 or -3 points per edge) -> S3 approximation -> rotation (outer shell slides along its edge, inner shells turn) -> C3 symmetric Levenberg-Marquardt, nodes free in the plane, no noise, float64 |
| `shell_c3_bary.py` | Like `shell_c3_search.py`, but the nodes stay inside the triangle by construction (barycentric coordinates b = s^2 / sum s^2), so every solution is a PI rule; `--auto` runs all variants with several processes, `--seq` replays one shell pattern, `--softplus` weights w = c ln(1 + e^x), `--damping scaled\|both` Marquardt scaled damping, `--exact`/`--relax` for the shell patterns, `--pull-inside` moves nodes on the boundary into the interior, `--staged` searches only Z nodes in stages (first steps of 2 and 3 points per edge, then with steps of 1), `--time-limit`, `--relax-from` (stages below this level are only counted, not run), `--skip-s3` (no S3 approximation: the shell pattern itself is rotated and the C3 solve starts with equal weights), `--noise-starts K --noise S --noise-seed Z` (K further C3 solves of every pattern from starts with noise proportional to the bubble function 27 b0 b1 b2 of the barycentric coordinates; use with a small `--win` so that a hopeless start ends quickly) |
| `shell_asym_search.py` | Triangle, exactly N nodes, no symmetry: every node and weight is free, started from a Gauss shell pattern (`pattern`, `rotated`, or `random` start, with seeded noise to leave the symmetric subspace); `--mode po` (nodes free in the plane) or `pi` (barycentric b = s^2 / sum s^2); `--wmin` lower bound of the weights (without it a node can escape to infinity with weight 0), `--polish-c3` rebuilds a C3 symmetric solution from its exact orbits |
| `anneal_c3.py` | Triangle, exactly Z nodes: annealing in the C3 symmetric subspace from the C3 approximation of `shell_c3_search.py` (noise larger near the centroid, nodes free in the plane), float64; writes every solution with seed and command |
| `asym_remove_node.py` | Triangle, exactly N - 1 nodes, no symmetry: starts from a stored PI rule with N nodes (a C3 symmetric rule has N = 0 or 1 modulo 3 nodes, an unsymmetric one can have 2 modulo 3), removes one node, gives its weight to the three nearest nodes, adds seeded noise and solves all nodes and weights with Levenberg-Marquardt, nodes inside by barycentric coordinates b = s^2 / sum s^2 (`AsymPI` of `shell_asym_search.py`); `--order weight\|random`, `--noise`, `--noises`, `--part`/`--parts`; writes every result with seed and command to `<out>/summary.txt` and a solution to `<out>/solution_<deg>_<N-1>_asym.json` |
| `cubature_search.py`, `verify_rules.py`, `cube_cert.py`, `run_cube_cert.py` | Cube: symmetric search and numerical check |
| `flat_ext_square8.py` | Square degree 8 with 15 = dim P4 nodes: exact flat-extension equations (10 quadratics in the 10 degree-9 moments), written in msolve format; pure Python. Numerically 16 finite solutions, 8 real, all symmetric images of CA-C2-08-15-PO (a node outside the square), so no PI rule with 15 nodes appears; `homotopy_square8.py` tracks all 1024 total-degree homotopy paths of this system |
| `flat_ext_cube6.py` | Open question cube degree 6: exact flat-extension equations (75 quadrics in the 36 degree-7 moments) for a 20-node rule, written in msolve format; pure Python, no numpy needed |

`cubature_search.py` (version 3) produced the cube rules CA-C3-21-486 … CA-C3-30-1324. It searches in a chosen subgroup of the cube group (Oh, Td, Th, O, T, …): orbit elimination, large-neighbourhood search with simulated annealing, a rank-ILP target structure, and warm starts from stored rules (`--refine T --sources dir`). Run `python3 cubature_search.py --help` for the options; the module docstring describes the method and lists the literature.

The rule files in `rules/` are the authoritative data. The build (`tools/build_atlas.py`) checks them independently of this code.
